In this Project we are trying to replicate the Tableau Dashboard in the week 14 WOW2025 challenge.

## Requirements

- Dashboard Size: 1400 x 800 px
- Create a bubble chart displaying each Product Name, segmented by region and category.
- Set the bubble size according to Sales and color according to Profit Ratio.
- Cluster products with lower profit ratios toward the center of the bubble chart.
- Clicking on Category name headers drills down to display subcategories for the clicked Category only
- Clicking the same Category name again drills back up.
- Display product-level details sorted by Profit Ratio in ascending order within the selected region.
- Match tooltips and formatting.
